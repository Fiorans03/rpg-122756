# L'Alchimista del Dungeon

RPG in Java dove il giocatore esplora un dungeon, raccoglie ingredienti, crea pozioni e combatte mostri.

## Esecuzione

Per compilare ed eseguire il progetto:

    ./gradlew build
    ./gradlew run

## Dichiarazione di utilizzo di strumenti AI

L'Intelligenza Artificiale (LLM) è stata utilizzata esclusivamente come strumento di supporto allo sviluppo (pair programming) e non come generatore autonomo del progetto. Nello specifico, l'AI è stata impiegata per:

1. Generazione di file di configurazione boilerplate (script Gradle, struttura iniziale dei package)
2. Refactoring e review del codice per garantire il rispetto dei principi SOLID e delle convenzioni di stile Java
3. Brainstorming architetturale e suggerimento di Design Pattern per migliorare l'estendibilità
4. Debugging e risoluzione di errori di compilazione

Tutte le decisioni di design, la definizione del dominio del gioco, il model design, l'implementazione della logica di business e la stesura della documentazione (Wiki) sono state effettuate dallo studente.
